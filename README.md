# prompt-distiller

**自分のAIコーディング履歴を解析して、「実際に何を頼んでいるか」を知り、それを精度の高い再利用プロンプト＋自動ルーターに蒸留するツールキット。**

> Mine your own Claude Code history → see what you *actually* ask AI for → distill it into precise, anti-fabrication prompt templates and an auto-router.

---

## きっかけ：思い込みが、データで崩れた

自分は「AIで"作る"人」だと思っていた。サイトを作る、コードを書く、コンテンツを量産する側だと。

確かめたことは一度もなかった。だから、自分の Claude Code 履歴を全部解析した。

- `~/.claude/projects` の全ログ＝**2,936ファイル / 2,927セッション**
- 各セッションの「最初に自分が打った依頼文」だけ抽出
- 自動で動くエージェント由来のプロンプト（**2,308件**）は "自分の依頼" ではないので除外
- 残った **手打ち依頼 619件** を用途で分類

結果（手打ち619件・多い順）:

| 用途 | 件数 |
|---|---:|
| リサーチ → 構造化レポート | **270** |
| 実装・構築 | 176 |
| コンテンツ再構成 | 161 |
| 動画・メディア | 150 |
| データ収集 | 149 |
| レビュー・監査 | 103 |

予想は外れた。最多は「作る」ではなく **「調べて、判断材料にする」** だった。作業はむしろ自動化に逃がしていて、自分の手は "判断する前のリサーチ" に集中していた。

**学び：プロンプトを磨く前に、"自分が何を繰り返し頼んでいるか" を見たほうがいい。思い込みはだいたい外れる。**

> 履歴を解析するだけなら、Claude Code 純正の `/insights` でもできる。このツールはその先 ―― 気づいた用途を、毎回ゼロから書かずに済む「型」に畳み、ラフに書けば自動で適切な型を呼ぶところまでやる。

## 中身

```
prompt-distiller/
├─ protocol.md              # §1 共通プロトコル =「捏造を拒否する」規律。差別化の核
├─ suites/
│  ├─ product-dev.md        # プロダクト開発12本(画面監査/QA/コスト/UX/QA/GTM…)
│  └─ recurring-tasks.md    # 繰り返し依頼10本(リサーチ/仮説検証/相場/リパーパス/動画/診断…)
├─ tools/
│  ├─ analyze_history.py    # 自分の履歴を解析して用途分布を出すスクリプト
│  └─ README.md
└─ skills/                  # Claude Code スキル(自動ルーター)。~/.claude/skills/ に置くだけ
   ├─ pdp/SKILL.md
   └─ flow/SKILL.md
```

### 設計で一番効いたもの：`protocol.md`

かっこいい役割設定ではなかった。学習源の違う3つのAI（Claude / Gemini / Codex）に自作プロンプトを敵対的レビューさせたら、全員が同じ急所を突いた:

> 「"分からない所は仮定で進めて" が強すぎる。欠けたら結論が逆転する入力まで推測で埋め、精密そうな"砂上の楼閣"を作る。」

なので全テンプレの土台にこれを入れた:

- **入力ゲート** … 致命的に足りない情報は、推測で埋めず止める
- **数値の規律** … 出典のない数字は `【推定】` と明記、架空の実績は作らない
- **検証義務** … 「直す」と言うなら、測る指標もセットで出す

## 使い方

### 1) プロンプト単体で使う
`suites/*.md` から使いたいテンプレをコピーし、**冒頭に `protocol.md` のプロトコルを貼り**、`《》` のスロットを埋める。埋められない欄は空でよい（モデルが仮定 or ブロッカーとして扱う）。

### 2) Claude Code スキルとして使う（自動ルーティング）
```bash
git clone https://github.com/AI-Driven-School/prompt-distiller
cp -r prompt-distiller/skills/pdp  ~/.claude/skills/
cp -r prompt-distiller/skills/flow ~/.claude/skills/
# suites/ を各スキルから参照できる場所に置く（SKILL.md内のパスを自分の環境に合わせる）
```
以後、ラフに書くだけで該当テンプレが起動する:
- 「リリース前にQA固めて」→ product-dev の Go/No-Go テンプレ
- 「競合を調べてレポートにして」→ recurring-tasks の T1 リサーチ

### 3) 自分の履歴を解析する
```bash
python3 tools/analyze_history.py
```
あなたの `~/.claude/projects` を読み、手打ち依頼の用途分布を出す。詳細は `tools/README.md`。出てきた "あなたの最頻用途" を、このスイートの作法（`protocol.md`）でテンプレ化すれば、あなた専用の道具箱になる。

## 思想

- **役割の誇張より、行動の指定**（×「世界最高のCTO」 ○「認知負荷を憎む」）
- **空スロットの暴発を止める**（埋める指示＋欠落時の挙動を決める）
- **緩い出力を契約化する**（表・判定・確信度）
- **捏造を構造で防ぐ**（このスイートは、自分自身の出力にもこの規律を課す）

詳しい型は `protocol.md` の **PROMPTS** チェックを参照。
